# Scripture audio sources

Runtime audio is streamed over HTTPS and selected by exact edition name. Lumen does not bundle or silently substitute recordings.

The Japanese host does not name the recording's text edition. It is isolated in its own adapter and this limitation must be resolved before a production release that claims synchronized exact-edition audio.
